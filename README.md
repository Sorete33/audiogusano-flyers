# Flyers

Drop zone for band flyers. Anything committed to `flyers/` is picked up by the
sync job in `Sorete33/gusano` and appears on the home page gallery.

The easiest way in is the **"Subí tu flyer!"** button on https://audiogusano.neocities.org/ —
it uploads straight to this folder from the browser, no account needed.

## Rules

- Images only: `.jpg`, `.jpeg`, `.png`, `.gif`, `.webp`, `.avif`, `.svg`
- Names are slugified on sync, so `Mi Banda 2026!.jpg` becomes `mi-banda-2026.jpg`
- Neocities free tier will not accept `.mp4`/`.mp3`, so anything else is skipped with a warning.
